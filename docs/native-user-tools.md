# User-defined native command tools (LiteRT-LM)

Each JSON file in `config/native_tools/` defines one **native Tool**, not a
Skill or MCP capability. The loader registers them with LiteRT-LM 0.18.0 using
the stock `litert_lm.Tool` API.

Example: `config/native_tools/get_current_time.json`:

```json
{
  "name": "get_current_time",
  "description": "Получить текущую дату и время компьютера, включая часовой пояс.",
  "command": ["/usr/bin/date", "+%Y-%m-%d %H:%M:%S %z"]
}
```

- `name` and `description` are exposed to the model as a zero-argument
  function. `command` is **not** exposed to the model.
- `command` is a fixed argv array; the executable must have an absolute path.
  Arguments are shell-quoted, never generated by the model. This first version
  intentionally does not support model-supplied arguments.
- Execution uses the existing bounded shell runner (timeout, output limit,
  process-group cleanup); commands run with CORE's operating-system privileges,
  in the configured shell working directory.
- Tools are loaded when CORE starts. Restart CORE after editing JSON.
- Tools are available to MANAGER by default. To grant one to an AGENT, add
  its exact `name` to that AGENT's `tools` allowlist JSON and restart CORE.
- The launcher reads `config/native_tools` by default. Override its directory
  using `CAT_AGENT_NATIVE_TOOLS_DIR`; direct CLI also supports
  `--external-tools-dir`.
