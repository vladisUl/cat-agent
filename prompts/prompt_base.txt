# База готовых навыков. Менеджер видит только name + description.
# Полный prompt выбранного навыка получает только назначенный агент.

[SKILL shell]
name: shell
description:
Работа в локальной Linux-системе и рабочем каталоге: просмотр и изменение файлов,
запуск программ и базовая диагностика системы.
prompt:
Ты получил навык shell.
Каждая команда выполняется через /bin/bash -c и запускается в рабочем каталоге из поля workspace.
Используй обычный синтаксис bash и реально установленные в системе команды.
Разрешены обычные возможности bash, включая &&, ||, ;, конвейеры, перенаправления,
переменные, command substitution и группировку команд.

Каждый ответ с командой по-прежнему должен содержать одну строку, как требует системный протокол.
Если для задачи требуется несколько связанных shell-действий, их можно объединить в одну обычную bash-строку.

Каждая строка выполняется отдельным процессом bash, который начинает работу из workspace.
Если требуется перейти в другой каталог и выполнить там действие, используй это в одной строке, например:
cd PATH && COMMAND

Не выдумывай несуществующие команды. Если команда завершилась ошибкой, используй фактический stdout,
stderr и exit_code из следующего сообщения runtime.
[/SKILL]

[SKILL mqtt]
name: mqtt
description:
Доступ к домашним данным и устройствам через MQTT: получение текущих показаний датчиков,
включая температуру и влажность на улице и дома, температуру в аквариуме и морозильнике,
и публикация MQTT-команд.
prompt:
Ты получил навык mqtt.

Для чтения текущего значения MQTT используй только команду:
mqtt_sub.sh <topic> <field>

Топик и доступные для него поля перечислены в context.
Сам выбери топик и поле по смыслу задачи и передай их двумя аргументами.
После успешного выполнения следующий вход содержит только значение выбранного поля,
без исходного JSON payload.
Не используй mosquitto_sub напрямую для чтения значений.

Пример:
mqtt_sub.sh zigbee2mqtt/temp_ulica humidity

Для публикации MQTT-команд используй mosquitto_pub.
Для mosquitto_pub broker_host и broker_port бери из context и обязательно указывай явно:
-h <broker_host> -p <broker_port>
Не используй localhost, если localhost не указан в context как broker_host.
Если для выполнения задачи не хватает обязательных данных, не пытайся их угадывать.
Сообщи, каких данных не хватает, способом, заданным системным протоколом.
[/SKILL]
