# База готовых навыков. Менеджер видит только name + description.
# Полный prompt выбранного навыка получает только назначенный агент.

[SKILL shell]
name: shell
description:
Безопасная работа в локальной Linux-системе и рабочем каталоге: просмотр и изменение файлов,
базовая диагностика системы.
prompt:
Ты получил навык shell.
Runtime принимает не произвольный bash, а проверенный набор команд без shell=True.

Доступны операции в WORKSPACE:
pwd
cd PATH
ls [-l] [-a] [PATH]
cat FILE
cat SOURCE >> DEST
sha256sum FILE
test -e PATH
test -f PATH
test -d PATH
[ -e PATH ]
[ -f PATH ]
[ -d PATH ]
mkdir [-p] PATH
touch FILE
cp SOURCE DEST
mv SOURCE DEST
rm FILE
echo TEXT
echo TEXT > FILE
echo TEXT >> FILE
./PROGRAM [ARG...]

Исполняемые файлы разрешено запускать только из WORKSPACE через ./имя или ./путь/имя.
Файл должен существовать, быть обычным файлом и иметь executable bit.

Для безопасного cat SOURCE >> DEST сначала обязательно прочитай SOURCE командой cat SOURCE.
Runtime разрешит append только если SOURCE после чтения не изменился.

Также доступны диагностические команды системы:
date
df
free
id
nproc
ps
uname
uptime
whoami

Файловые операции ограничены WORKSPACE. Не используй shell expansion, command substitution,
конвейеры, ;, &&, || и другие управляющие операторы. Если нужной команды нет в списке,
не подменяй её выдуманной командой: сообщи об отсутствующей возможности способом, заданным системным протоколом.
[/SKILL]

[SKILL mqtt]
name: mqtt
description:
Доступ к домашним данным и устройствам через MQTT: получение текущих показаний датчиков,
включая температуру на улице, дома, в аквариуме и морозильнике, и публикация MQTT-команд.
prompt:
Ты получил навык mqtt.
Для работы с MQTT доступны команды:
mosquitto_sub
mosquitto_pub

В CONTEXT заданы broker_host и broker_port.
В КАЖДОЙ команде mosquitto_sub и mosquitto_pub обязательно указывай их явно:
-h <broker_host> -p <broker_port>
Никогда не полагайся на broker по умолчанию и не используй localhost, если localhost не указан в CONTEXT как broker_host.
Если broker_host или broker_port отсутствуют в CONTEXT, сообщи об отсутствующих данных способом, заданным системным протоколом.

Для получения текущего значения используй однократную подписку:
mosquitto_sub -h <broker_host> -p <broker_port> -t <topic> -C 1 -W 5
Для публикации используй mosquitto_pub с явными -h <broker_host> -p <broker_port> и параметрами, соответствующими TASK и CONTEXT.
Если для выполнения задачи не хватает обязательных данных, не пытайся их угадывать.
Сообщи, каких данных не хватает, способом, заданным системным протоколом.
[/SKILL]
