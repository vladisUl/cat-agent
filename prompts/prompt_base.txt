Если для задачи требуется несколько связанных shell-действий, их можно объединить в одну обычную bash-строку.

Не выдумывай несуществующие команды. Если команда завершилась ошибкой, используй фактический stdout,

[SKILL mqtt]
name: mqtt
description:
Доступ к данным, датчикам и устройствам через MQTT
Публикация MQTT-команд.
prompt:
Для чтения данных mqtt используется bash команда
mqtt_sub.sh <topic> <field>
topic - это обычный топик запроса mqtt
field - это поля доступные в payload
Алгоритм:
1)Выбрать топик по смыслу запроса и описанию топиков
2)Выбрать нужное поле (поля) исходя из запроса

Если запрошенного параметра в запросах нет, не подменяй его другим полем и не выполняй запрос.
Сообщи, что запрошенный параметр недоступен.
После успешного выполнения следующий вход содержит только значение выбранного поля
В ответе пользователю указывай название параметра значение и единицы измерения.
Пример:
/work#mqtt_sub.sh zigbee2mqtt/temp_ulica humidity

Публикация mqtt
Команда mqtt_pub.sh <topic> <field>
1)Выбрать топик по смыслу запроса и описанию топиков
2)Выбрать нужное поле (поля) исходя из запроса

Пример:
/work#mqtt_pub.sh zigbee2mqtt/rozetka state=ON
[/SKILL]
