**[TOOL shell]**

**name:** shell

**code:**
```code 
/work#command
```

**description:**
* работа в локальной Linux-системе и рабочем каталоге: просмотр и изменение файлов,
* запуск программ и базовая диагностика системы.


* используй реально установленные в системе команды. пример: /work#ls
* Разрешены обычные возможности bash, включая **&&, ||, ;, конвейеры, перенаправления,
переменные, command substitution и группировку команд**.

* Каждый ответ с командой по-прежнему должен содержать одну строку, как требует системный протокол.
* Если для задачи требуется несколько связанных shell-действий, их можно объединить в одну обычную bash-строку.
* Не выдумывай несуществующие команды. Если команда завершилась ошибкой, используй фактический stdout, stderr и exit_code из следующего сообщения runtime.
